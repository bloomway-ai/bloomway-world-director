# Security

## Reporting a vulnerability

If you believe you have found a security issue in **Bloomway World Director** (this open-source repository), please report it privately:

**Email:** info@bloomway.ai  
**Subject line:** `[Security] Bloomway World Director`

Include a description of the issue, steps to reproduce, and impact if known. Please do not open a public GitHub issue for undisclosed vulnerabilities.

We do not publish a guaranteed response-time SLA in this document. Reports are reviewed as they arrive.

## Scope

This policy applies to source code and documentation **in this repository**. It does **not** cover:

- The Bloomway web application, APIs, or hosted infrastructure (report those through [https://bloomway.ai](https://bloomway.ai) contact channels as applicable).
- Third-party services you connect to yourself.

## Supported versions

Security fixes are intended for the **current default branch** of this repository. Older tags may not receive backports unless noted in release notes.
