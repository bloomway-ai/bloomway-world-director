# Contributing

Thank you for helping improve Bloomway World Director.

## What we welcome

- New example scenes and camera-move descriptions (with screenshots or short screen recordings from **real** blockout previs)
- Documentation and translations (README.zh-CN.md is maintained alongside README.md; other locales may follow)
- Bug reports and reproducible steps
- Integrations that respect the [MIT License](LICENSE) and [TRADEMARKS.md](TRADEMARKS.md)

## What runs in pull requests

CI will verify installs, builds, and example validation when those workflows exist. Please do not add license terms in comments or docs that conflict with MIT for code in this repo.

## Co-creation

Bloomway AI welcomes developers and filmmaking enthusiasts to build together. Optional contact: **info@bloomway.ai** — share ideas before large changes if you want alignment on direction.

By contributing, you agree that your contributions are licensed under the same MIT License as the project (subject to final copyright-holder confirmation documented in the repo).
