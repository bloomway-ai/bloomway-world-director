# Default branding in the official Studio UI

This describes the **official** `apps/studio` builds we maintain. It is **not** an additional license condition beyond MIT.

## Copy (English UI in v0.1)

- Title line: **Bloomway World Director**
- Subline: **An open-source project by Bloomway AI**

## Placement

- Persistent **footer** or **About** panel entry (not a blocking modal).
- Links: official GitHub repository URL (set at release time) and [https://bloomway.ai](https://bloomway.ai).

## What we do not do

- Force attribution in **exported video** or still frames.
- Network verification or feature locks to prevent forks from changing UI.
- Require Bloomway login for local open-source functionality.

`apps/studio/src/components/ProjectAttribution.tsx` (to be added when Agent mode enables code files)—see [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md).
