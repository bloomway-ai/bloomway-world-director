# Street confrontation (demo plan)

Short **14s** blocking beat: two capsule characters (Runner / Rival) on an Edo rainy-night world, with a four-key camera path.

Loaded in OSS Studio via composer lines such as `load street drama` or a one-line story prompt (see `ossLocalComposer.ts`).

Recorded in `media/demo-drama.mp4` (`npm run record:demos`).
